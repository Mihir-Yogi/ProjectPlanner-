# ProjectPlanner

ProjectPlanner is a project discovery and planning workspace. The current frontend milestone implements the Dashboard only.

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current scope

- Next.js App Router with TypeScript
- Dashboard empty state and responsive navigation shell
- Project creation and unfinished destinations remain disabled until their pages are approved and implemented
- No backend, project persistence, or sample project data is included

## Checks

```bash
npm run lint
npx tsc --noEmit
npm run build
```
